# Mercearia - Releases e Atualizações

Este repositório é utilizado exclusivamente para hospedar, organizar e distribuir os ficheiros executáveis, instaladores e notas de versão (releases) do sistema **Mercearia**.

---

## 🚀 Como baixar a versão mais recente?

Para descarregar os executáveis e ficheiros de atualização mais recentes:

1. Acesse a secção de **[Releases](../../releases)** deste repositório (ou na barra lateral à direita).
2. Localize a versão mais recente identificada pela etiqueta **`Latest`**.
3. Na secção **Assets**, faça o download do ficheiro correspondente:
   * `update_1.201.zip` – Ficheiro de atualização do sistema.
   * `version.json` – Ficheiro de verificação de versão.

---

## 🛠️ Notas de Versão

As alterações, correções e novas funcionalidades são descritas diretamente na página de detalhes de cada release individual.
